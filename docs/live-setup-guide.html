Prerequisites (US)
Accounts on both regulated US venues

Polymarket US

  • Polymarket US account with KYC complete (via the Polymarket US iOS app).
  • Funded trading balance on Polymarket US (custodial USDC.e — not a self-custody Polygon wallet).
  • API keys from polymarket.us/developer — you get a key_id (UUID) and base64 secret_key (Ed25519).

Kalshi

  • Kalshi account (US residents eligible).
  • API key from Account → Profile → API Keys (kalshi.com/account/profile).
  • Download the RSA private key immediately — Kalshi does not store it.
  • Funded balance in your Kalshi account for live orders.
  • Python 3.10+ and project dependencies installed locally.
Do not use for Polymarket US: Polygon wallet private key, POLYMARKET_PRIVATE_KEY, or scripts/generate_polymarket_credentials.py — those are for Polymarket Global only.

Gather API credentials
Polymarket US + Kalshi (not Global Polygon keys)

Polymarket US — from the developer portal after KYC:

  1. Complete KYC on the Polymarket US iOS app
  2. Generate API keys at polymarket.us/developer
  3. Save key_id and secret_key (base64 Ed25519 — shown once)

Kalshi — from profile settings:

  1. Create API key → copy Key ID
  2. Download private key (.txt / PEM) — one-time only
  3. Optional: use demo.kalshi.co sandbox before production
Keys from polymarket.us/developer go into config.live.us.yaml via env vars.

Set environment variables
Required for live mode validation

Add to ~/.zshrc, a .env file (gitignored), or your session:

~/.zshrc or .env
# Polymarket US
export POLYMARKET_PLATFORM=us
export POLYMARKET_US_KEY_ID="..."
export POLYMARKET_US_SECRET_KEY="..."
export KALSHI_API_KEY_ID="..."
export KALSHI_PRIVATE_KEY_PATH="/path/to/kalshi-key.pem"
export KALSHI_API_URL="https://external-api.kalshi.com/trade-api/v2"
# Sandbox: https://demo-api.kalshi.co/trade-api/v2
VariablePlatformPurpose
POLYMARKET_US_KEY_IDPolymarket USAPI key UUID from developer portal
POLYMARKET_US_SECRET_KEYPolymarket USBase64 Ed25519 secret key
KALSHI_API_KEY_IDKalshiKALSHI-ACCESS-KEY header
KALSHI_PRIVATE_KEY_PATHKalshiRSA-PSS request signing
Legacy Global vars (POLYMARKET_PRIVATE_KEY, POLYMARKET_API_KEY, etc.) are for international Polymarket only — ignore them for your US setup.
